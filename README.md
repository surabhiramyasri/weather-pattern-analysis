# Weather Pattern Analysis

## Project Overview

Weather Pattern Analysis is a data analysis project that studies rainfall patterns using historical weather data from India.

The project analyzes rainfall data to identify patterns and variations across different years and regions.

## Objectives

* Analyze historical rainfall data
* Find rainfall patterns and variations
* Calculate basic rainfall statistics
* Visualize weather data using charts
* Understand yearly and regional rainfall trends

## Dataset

The project uses an India weather and rainfall dataset in CSV format.

**Dataset file:** `india_weather_rainfall_small.csv`

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Structure

```text
weather-pattern-analysis/

├── india_weather_rainfall_small.csv

```

## How to Run

1. Download or clone this repository.
2. Install the required Python libraries using:

```bash
pip install -r requirements.txt
```

3. Run the Python program:

```bash
python weather_pattern_analysis.py
```

## Analysis Performed

The project performs:

* Data loading
* Data preprocessing
* Rainfall analysis
* Statistical analysis
* Data visualization
* Weather pattern identification

## Expected Output

The program generates visualizations that help understand rainfall patterns and changes in the dataset.

## Conclusion

This project demonstrates how Python-based data analysis and visualization can be used to study weather and rainfall patterns. The analysis can help in understanding historical rainfall trends and making the data easier to interpret.
